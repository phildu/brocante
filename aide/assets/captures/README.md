# Captures d'écran du centre d'aide

Aucune capture réelle n'a été produite pendant cette construction : les fichiers ci-dessous sont des fiches à tourner sur le serveur local. **Ne jamais fabriquer une capture** ni réutiliser une capture de production.

## Convention de nommage

`<tutoriel>-<numéro>-<geste>.png`, par exemple `plan-03-poser.png`. Le nom exact attendu par chaque tutoriel est dans sa fiche `fiche-<slug>.md` et dans la page du tutoriel. Déposer un fichier au bon nom dans ce dossier remplace automatiquement l'emplacement « capture à faire » par l'image.

## Règles de prise de vue

- Capturer sur le serveur local, jamais sur la production avec de vraies données.
- Utiliser un compte de test et une galerie de démonstration.
- Format PNG, largeur 1280 px pour le bureau, 390 px pour le téléphone.
- Flouter ou masquer les données personnelles et les secrets.
- Nommer le fichier exactement comme indiqué, dans aide/assets/captures/.
- Statut tant que l'image n'existe pas : `a-faire`. Ne pas laisser une capture ancienne à la place.
- Vérifier qu'aucun nom, e-mail, téléphone, IBAN, jeton ou mot de passe n'est lisible.
